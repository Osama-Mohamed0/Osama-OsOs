# إنجاز — Injaz

تطبيق سطح مكتب لويندوز لمتابعة **المهام** و**الإنتاجية** و**العادات**، بواجهة عربية كاملة (من اليمين لليسار)، يعمل دون إنترنت وتبقى بياناتك على جهازك.

يعمل على **ويندوز 10 و11، بنظامي 32 بت و64 بت** — المثبّت يختار النسخة المناسبة لجهازك تلقائياً.

## المزايا

**المهام**
- إضافة سريعة بضغطة Enter، مع موعد وأولوية وتصنيف.
- تفاصيل كاملة: ملاحظات، وقت تذكير، مهام فرعية، تكرار (يومي / أيام العمل / أسبوعي / شهري).
- عرض: اليوم (مع المتأخرة)، القادمة، كل المهام، المنجزة — مع بحث وترتيب وتصفية حسب التصنيف.
- تراجع فوري عن الإنجاز أو الحذف.

**التركيز (بومودورو)**
- مؤقّت تركيز واستراحات قصيرة وطويلة بمدد قابلة للتعديل.
- ربط الجلسة بمهمة وحساب وقت التركيز لكل مهمة.
- يظهر الوقت المتبقي في عنوان النافذة وشريط تقدّم على أيقونة شريط المهام، مع صوت وإشعار عند الانتهاء.

**العادات**
- عادات يومية أو لأيام محددة، مع هدف عددي (مثل 8 أكواب ماء).
- تسجيل بنقرة لآخر 7 أيام، السلسلة الحالية وأفضل سلسلة ونسبة الالتزام.
- سجل حراري لكل عادة يمكن التسجيل منه بأثر رجعي، واقتراحات جاهزة (ورد القرآن، الصلاة في وقتها، القراءة…).

**الإنتاجية والإحصائيات**
- «نقاط اليوم» من 100 = متوسط تحقيق أهدافك اليومية (المهام، دقائق التركيز، العادات)، وسلسلة الأيام المنتجة.
- مخططات لآخر 7 / 30 / 90 يوماً مع المقارنة بالفترة السابقة، والالتزام بكل عادة، والإنجاز حسب التصنيف وحسب يوم الأسبوع، مع عرض جدولي بديل.

**عام**
- مظهر فاتح وداكن (أو حسب النظام)، وتكبير الواجهة.
- إشعارات ويندوز للتذكيرات، وتذكير يومي بالعادات المتبقية.
- التشغيل مع بدء ويندوز، والبقاء بجانب الساعة عند الإغلاق (اختياري).
- حفظ تلقائي، ونسخة احتياطية يومية تلقائية (آخر 14 يوماً)، وتصدير/استيراد يدوي.

## التثبيت على ويندوز

1. افتح تبويب **Actions** في هذا المستودع، واختر آخر تشغيل ناجح لـ **Build Windows app**.
2. نزّل الملف **Injaz-Windows** من قسم Artifacts وفك ضغطه. ستجد:
   - `Injaz-Setup-1.1.0.exe` — مثبّت عادي (اختصار على سطح المكتب وقائمة ابدأ).
   - `Injaz-Portable-1.1.0.exe` — نسخة محمولة تعمل مباشرة دون تثبيت.
3. عند أول تشغيل قد يظهر تحذير SmartScreen لأن التطبيق غير موقّع رقمياً: اضغط **More info** ثم **Run anyway**.

> لإصدار نسخة رسمية في صفحة Releases: أنشئ وسماً مثل `v1.0.0` وادفعه، وسيُرفق الملفان تلقائياً.

## تطبيق أندرويد والمزامنة مع الكمبيوتر

نفس التطبيق متاح للهاتف (أندرويد 7 فما فوق)، ويتزامن مع الكمبيوتر **عبر الواي فاي في البيت مباشرة** — دون إنترنت أو حسابات أو خوادم، والبيانات مشفّرة برمز الربط.

**التثبيت:** من تبويب **Actions** ← آخر تشغيل ناجح لـ **Build Android app** ← نزّل **Injaz-Android** وفك ضغطه، ثم انقل `Injaz-Android.apk` للهاتف وافتحه (اسمح بالتثبيت من هذا المصدر عند السؤال).

**الربط (مرة واحدة):**
1. على الكمبيوتر: الإعدادات ← المزامنة مع الهاتف ← فعّل المزامنة. إن ظهرت نافذة جدار حماية ويندوز فاختر «السماح».
2. على الهاتف: الإعدادات ← المزامنة مع الكمبيوتر ← **مسح رمز QR**.

بعدها تتم المزامنة تلقائياً كلما كان الجهازان على نفس الشبكة وإنجاز مفتوح على الكمبيوتر (أو مصغّر بجانب الساعة). ما تضيفه على الهاتف خارج البيت يُحفظ عليه ويُدمج عند عودتك؛ وإن عُدّلت نفس المهمة على الجهازين يُعتمد التعديل الأحدث.

> مفتاح توقيع التطبيق (`mobile/android/app/injaz-personal.keystore`) محفوظ في المستودع عمداً حتى تُثبَّت التحديثات فوق النسخة القديمة دون حذفها. هذا مناسب لتطبيق شخصي غير منشور في المتجر.

## التشغيل من الكود المصدري

يتطلب [Node.js](https://nodejs.org) الإصدار 20 أو أحدث:

```bash
npm install
npm start
```

ولبناء ملف التثبيت بنفسك على ويندوز: `npm run dist` (تظهر الملفات في مجلد `dist`).

## أين تُحفظ بياناتي؟

في الملف `%APPDATA%\Injaz\injaz-data.json`، والنسخ الاحتياطية اليومية في `%APPDATA%\Injaz\backups`. يمكنك فتح المجلد من **الإعدادات ← فتح مجلد البيانات**.

## اختصارات لوحة المفاتيح

| الاختصار | الوظيفة |
|---|---|
| `Ctrl + N` | مهمة جديدة |
| `Ctrl + F` | بحث في المهام |
| `Ctrl + 1 … 6` | التنقل بين الشاشات |
| `مسافة` | تشغيل/إيقاف المؤقت (في شاشة التركيز) |
| `Ctrl + +` / `Ctrl + −` / `Ctrl + 0` | تكبير / تصغير / إعادة حجم الواجهة |
| `Esc` | إغلاق النافذة المنبثقة |

## البنية التقنية

- [Electron](https://www.electronjs.org) مع JavaScript عادي دون أطر عمل أو خطوة بناء للواجهة.
- `main.js`: النافذة، الحفظ في ملف JSON (كتابة ذرّية + نسخ احتياطية)، الإشعارات، أيقونة شريط المهام.
- `sync-server.js`: خادم المزامنة المحلي مع الهاتف (عبر الشبكة المنزلية فقط، مشفّر).
- `preload.js`: جسر آمن (`contextIsolation` و`sandbox`) بين الواجهة والنظام.
- `src/`: الواجهة (HTML/CSS/JS) المشتركة بين الكمبيوتر والهاتف، والخط المضمّن Cairo (رخصة OFL).
- `mobile/`: تطبيق أندرويد ([Capacitor](https://capacitorjs.com)) يبني نفس الواجهة مع ملفات خاصة بالهاتف (الإشعارات، زر الرجوع، مسح QR).
