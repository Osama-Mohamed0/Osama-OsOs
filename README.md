# Osama-OsOs

## TerraMind Studio — AI-native mining CAD prototype

Interactive web prototype of a modern Surpac alternative: drillholes, IDW block model,
implicit orebody, pit shell optimisation, live economics, and a bilingual (Arabic/English)
AI copilot that turns commands into JSON tool calls.

- App: [`terramind-studio/index.html`](terramind-studio/index.html) — open in a browser (served by GitHub Pages from `main`).
- Desktop port plan: [`terramind-studio/PYTHON_PORT.md`](terramind-studio/PYTHON_PORT.md)

All data is synthetic.
