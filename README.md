# Osama-OsOs

## TerraMind Studio — mining geology, resource estimation & pit planning

A complete browser application: drillhole database (import, desurvey, validation, compositing), DTM/strings (Surpac `.str`, DXF), variography and ordinary kriging, RBF implicit solids, Lerchs-Grossmann pit optimisation, scheduling with NPV/IRR, executive reports, and a bilingual AI copilot (Claude / OpenAI / Gemini or offline).

- Open the app: [`terramind-studio/index.html`](terramind-studio/index.html) (double-click on Windows, or via GitHub Pages)
- Guide (Arabic/English): [`terramind-studio/README.md`](terramind-studio/README.md)
- Engine tests: `node terramind-studio/tests/run-tests.js`
- First prototype kept for reference: `terramind-studio/prototype-v0.html`
